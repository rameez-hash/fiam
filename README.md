# Fiam Pakistan — Next.js

Premium product website for **Fiam Pakistan** ([fiam.com.pk](https://fiam.com.pk)), rebuilt in Next.js with Lucent Lighting Studio–inspired layout and SEO / AI-SEO standards.

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS 4
- Remote product imagery from [fiam.cc](http://www.fiam.cc/)

## Brand

- **Name:** Fiam Pakistan
- **Email:** info@fiam.com.pk
- **Domain:** https://fiam.com.pk

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```
NEXT_PUBLIC_SITE_URL=https://fiam.com.pk
```

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — start production server
- `npm run lint` — ESLint
